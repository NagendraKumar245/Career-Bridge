1. Introduction

1.1 Project Overview

CareerBridge is an intelligent, full-stack career platform engineered to address the systemic challenges faced by college seniors and fresh university graduates during their transition into the technology industry. Traditional recruitment channels frequently fail entry-level candidates by relying on static keyword indexing, opaque algorithmic filters, and rigid tenure thresholds. CareerBridge solves this by implementing natural language text vectorization, automated layout-aware resume parsing, mathematical skill gap analysis, and tailored learning pathway recommendations.

1.2 Problem Statement

Contemporary online employment portals (including LinkedIn, Indeed, and corporate recruitment sites) present four foundational hurdles for early-career technologists:

  • Experience Thresholds: Positions designated as "entry-level" routinely demand 2–3 years of commercial production experience.
  • Applicant Tracking System (ATS) Disqualification: Algorithmic keyword scanners disqualify applicants based on phrasing mismatches, disregarding demonstrated project competence and foundational skills.
  • Absence of Remedial Feedback: Rejected candidates receive binary automated rejections offering zero diagnostic insight into the specific technical gaps that led to disqualification.
  • Fragmented Skill Remediation: Students lack centralized market intelligence to discern which emerging tools to prioritize and where to locate accredited educational resources.

1.3 Project Objectives

The engineering objectives realized in this project are:

  • To build a modern, responsive Single Page Application (SPA) using React 18 and Tailwind CSS v3 with protected and administrative route guards.
  • To implement an automated PDF resume ingestion pipeline in Python utilizing pdfplumber to extract structured skills across an 88-skill taxonomy.
  • To design a hybrid AI recommendation engine combining Term Frequency-Inverse Document Frequency (TF-IDF) with Cosine Similarity and prerequisite verification.
  • To calculate mathematical skill gaps across target jobs and aggregate market-wide competency deficits using frequency prioritization.
  • To query curated course catalogs (Coursera, Udemy, edX) and provide structured learning pathways matching candidate deficits.
  • To provide an administrative portal for live governance of platform statistics, student applicant records, and job posting lifecycles.

1.4 Scope and Target Users

The platform scope encompasses university seniors, recent engineering graduates, recruitment administrators, and campus placement cells. The system automates candidate profile creation, job compatibility discovery, one-click application submission, and skill portfolio updates.

2. Literature Survey & Requirement Analysis

2.1 Existing Systems & Shortcomings

Existing job boards operate primarily via relational database queries (e.g., SQL LIKE pattern matching) or boolean filters. In these legacy architectures, candidates who possess relevant skills but omit specific synonyms or acronyms are routinely discarded. Furthermore, existing portals maintain no diagnostic feedback loop: once an application is submitted, candidates receive no guidance regarding how to close technical deficits.

2.2 Proposed Solution & Value Addition

CareerBridge formulates candidate profiles and job descriptions as multidimensional semantic vectors. By analyzing term frequencies and document orientation, the platform identifies conceptual alignment even when exact phrasing differs, while simultaneously validating core mandatory prerequisites. Additionally, the system provides transparent skill gap breakdowns and prioritized course recommendations, transforming rejections into structured upskilling opportunities.

2.4 Functional Requirements

The functional requirements established for the system include:

  • FR-01 (Authentication): Registration, login, and session validation using stateless JWT tokens with role separation (Student vs. Admin).
  • FR-02 (Candidate Profiling): Management of education history, portfolio projects, and technical skills with proficiency levels.
  • FR-03 (Resume Parsing): Automated ingestion of PDF resumes, text extraction via pdfplumber, and taxonomy matching.
  • FR-04 (AI Matching): Calculation of compatibility scores (0–100%) using TF-IDF vectorization and cosine similarity.
  • FR-05 (Skill Gap Analysis): Mathematical set-difference derivation of missing requirements for targeted jobs and market-wide demands.
  • FR-06 (Course Recommendations): Dynamic mapping of candidate skill gaps to curated courses sorted by frequency and rating.
  • FR-07 (Application Pipeline): Submission of job applications and tracking through status stages (Applied, Reviewed, Interview, Offered).
  • FR-08 (Admin Governance): Management of student applicant rosters, job creation/editing, and application status updates.

2.5 Non-Functional Requirements

The non-functional specifications enforce sub-second matching latency (< 200 ms), salted cryptographic password security (PBKDF2-SHA256 with 600,000 iterations), responsive viewport design across mobile and desktop devices, and database referential integrity via foreign key cascades.

3.2 Data Flow Architecture

Client requests are initiated through the centralized Axios client in api.js. The request interceptor dynamically appends the JWT Bearer token from local storage. The Vite proxy forwards requests matching /api/* to Flask on port 5000. Flask validates token signatures, invokes the appropriate service modules (e.g., Scikit-learn or SQLAlchemy), and returns JSON responses.

4. Methodology & Implementation Details

4.1 AI Job Recommendation Engine

CareerBridge implements a hybrid scoring pipeline that evaluates both semantic context and explicit skill fulfillment.

4.1.1 Natural Language Vectorization (TF-IDF)

Candidate skills and synthesized job specifications are transformed into vector spaces using Scikit-learn's TfidfVectorizer. Sublinear term frequency scaling is applied to prevent repetitive keyword stuffing from skewing recommendations:

TF(t, d) = 1 + ln(count(t, d)) # Sublinear term frequency IDF(t, D) = ln((1 + |D|) / (1 + df(t))) + 1 # Smoothed inverse document frequency TF-IDF = TF(t, d) * IDF(t, D) # Normalized vector representation

4.1.2 Multidimensional Cosine Similarity

Cosine similarity calculates the angular orientation of the student term vector u and the job specification vector v:

Cosine_Similarity(u, v) = (u . v) / (||u||_2 * ||v||_2) = SUM(u_i * v_i) / [ SQRT(SUM(u_i^2)) * SQRT(SUM(v_i^2)) ]

4.1.3 Hybrid Scoring Formula

The final compatibility score blends 60% semantic cosine similarity with 40% direct prerequisite skill overlap, yielding a calibrated 0–100% score:

Direct_Overlap = |Student_Skills INTERSECT Job_Skills| / |Job_Skills| Match_Score = [ 0.60 * Cosine_Similarity + 0.40 * Direct_Overlap ] * 100

4.2 Automated Resume Parsing & Skill Taxonomy

The resume ingestion pipeline receives uploaded PDF files, validates MIME types, and uses pdfplumber to extract text coordinates. Text streams are scanned against an 88-skill taxonomy using word-boundary regular expressions (\b) to eliminate substring collisions (such as matching "Java" within "JavaScript").

4.3 Skill Gap Analysis & Market Demand Aggregation

For an individual job, missing competencies are derived via mathematical set difference: Missing = Required_Job_Skills \ Candidate_Skills. For market-wide prioritization, the backend queries the student's top 10 recommended roles and aggregates missing competencies using Python's collections.Counter, identifying which skills unlock the greatest number of opportunities.

4.4 Course Recommendation Subsystem

Identified skill deficits are mapped to the courses table via relational joins on skill names. Courses from Coursera, Udemy, and edX are prioritized based on demand frequency, difficulty, and user ratings.

4.5 Security Architecture & Role-Based Access Control

Authentication utilizes JSON Web Tokens signed with HMAC-SHA256, carrying user IDs and role claims. Passwords are encrypted using salted PBKDF2-SHA256 hashes with 600,000 iterations. Administrative operations are protected via the custom @admin_required decorator, which inspects JWT claims and returns HTTP 403 Forbidden for unauthorized requests.

6. Conclusion & Future Scope

6.1 Project Summary & Accomplishments

CareerBridge successfully demonstrates the practical application of Natural Language Processing and modern full-stack software engineering to address the fresh graduate employment dilemma. By harmonizing automated resume parsing, hybrid TF-IDF cosine similarity scoring, interactive skill gap analysis, and curated course recommendations, the platform replaces opaque recruitment filters with transparent, data-driven career pathways.

6.2 Key Technical Learnings

The project reinforced critical software engineering lessons: the necessity of hybrid scoring (combining statistical text similarity with strict prerequisite verification), defensive frontend property handling to prevent React rendering crashes, and normalized relational junction tables for flexible many-to-many entity mappings.

6.3 Future Scope & Enhancements

Future iterations of the platform can expand upon these foundational capabilities:

  • Deep Transformer Embeddings: Integrating Sentence-BERT or fine-tuned domain LLMs to capture deeper semantic relationships across nuanced project descriptions.
  • AI Mock Interviewer: Embedding a real-time conversational AI assistant that conducts simulated technical and behavioral interviews tailored to the specific target role.
  • Automated LinkedIn Ingestion: Enabling direct profile imports via OAuth 2.0 social integrations to supplement uploaded PDF resumes.
  • Employer Recruitment Portal: Expanding the administrative interface into a multi-tenant corporate portal where verified enterprise employers can directly search and message high-matching candidates.
