Key Viva Question:
How does AuthContext ensure state persistence and route security?
On initial load, useEffect checks localStorage for a valid JWT token. If present, it attaches it to Axios headers and sets the user state. Route guards intercept unauthenticated transitions and redirect users to /login.

Key Viva Question:
How are passwords stored and how does the backend verify API requests?
Passwords are salted and hashed using PBKDF2/SHA256 via werkzeug.security. Protected routes inspect the Authorization: Bearer <token> header using @jwt_required and abort with 401 if invalid.

Key Viva Question:
What is the mathematical formulation of Cosine Similarity and why is it used?
$$\text{Cosine Similarity}(u, v) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}$$ It measures the cosine of the angle between two multi-dimensional TF-IDF vectors, making matching invariant to document length so brief resumes aren't penalized.

Explain the database schema relationship between User, StudentProfile, and Application.

Key Viva Question:
What was the root cause of the React resume upload blank screen bug and how did you resolve it?
The backend returned extracted skills as objects [{ name, category }]. Profile.jsx attempted to render {skill} directly in JSX rather than {skill.name}, causing a React child unhandled exception.
