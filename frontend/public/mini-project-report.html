Abstract

CareerBridge is a responsive, AI-powered web platform designed to empower undergraduate engineering students by providing automated resume analysis, mathematical job-fit scoring, and personalized skill gap diagnostics. Traditional collegiate placement processes rely on manual, keyword-limited screening that leaves students without actionable insights into why they fail to qualify for desired job profiles. CareerBridge bridges this divide by providing an end-to-end recruitment intelligence system. The platform incorporates a client-side single-page architecture built with React 19 and a modular Flask RESTful backend service. Students upload standard PDF resumes, which are parsed via stream extraction to identify technical competencies. A natural language processing engine applies TF-IDF vectorization and Cosine Similarity to calculate exact percentage matches against live corporate job postings. In addition, an aggregated Placement Readiness Score assesses student employability, while an automated course recommendation pipeline suggests specific learning roadmaps to close detected skill gaps.

1. Introduction

1.1 Problem Statement

Undergraduate engineering students frequently lack structured guidance on how their academic skills translate into modern industry hiring requirements. Generic job portals function primarily as broadcast boards, failing to provide students with transparent assessments of why their applications are rejected. Furthermore, students often possess fragmented technical skills without understanding the specific framework stacks expected by recruiters, leading to missed placement opportunities.

1.2 Objectives

  • Automated Skill Extraction: Provide a centralized, free platform where students can evaluate their resumes against actual job listings.
  • Algorithmic Job Matching: Implement algorithmic TF-IDF vectorization and Cosine Similarity to calculate mathematical job-fit percentages.
  • Readiness Scoring: Compute an aggregated Placement Readiness Score reflecting profile completeness and skill density.
  • Faculty Analytics: Equip placement coordinators with institutional dashboards to track placement readiness across branches.

1.3 Scope

The project covers a complete web application featuring authentication, student dashboard, PDF resume uploader, machine learning matching engine, job portal with filter controls, and an administrative tracking interface. Payment processing and native mobile application builds are outside the scope of this project.

1.4 Success Criteria

A candidate can log in, upload a standard PDF resume, view extracted skills within two seconds, inspect matched job openings sorted by relevance, and apply with a single click. All interfaces must render responsively on mobile and desktop viewports without unhandled exceptions.

3.2 Data Flow

The student uploads a PDF resume. The Flask API ingests the binary, invokes pdfplumber for stream extraction, applies canonical regex matching, constructs TF-IDF vectors, and computes Cosine Similarity with published job postings.

[Student Browser] -> Upload PDF -> [Flask API] -> [pdfplumber Parser] ^ | | v [Client Dashboard] <- Return Matches <- [TF-IDF Cosine Matcher]
Figure 2: Resume Ingestion and Matching Data Flow

3.3 Data Design

The core relational entities comprise User (credentials and role), StudentProfile (skills, CGPA, department), Job (qualifications, stipend, role), Application (association tracking application state), Course (learning links), and Skill (canonical vocabulary).

4.2 Major Modules

Resume Parsing Module: Extracts clean text from PDF documents using coordinate sorting and normalizes keywords against a 300+ technical skill lexicon. Matching Module: Encodes profiles and job postings into sparse matrices to compute cosine distance. Job Portal: Supports real-time keyword search and application status updates.

4.3 Key Algorithm / Logic

Job-candidate relevance is evaluated via mathematical Cosine Similarity between TF-IDF document vectors:

Cosine Similarity(u, v) = (u · v) / (||u||2 × ||v||2)

The Placement Readiness Score synthesizes profile completion (20%), verified skill count (40%), and average job compatibility (40%) to output a 0–100% employability index.

4.4 Security and Privacy

Candidate passwords are encrypted using salted PBKDF2/SHA-256 hashes. Endpoints verify incoming Bearer tokens, and file uploads are restricted to PDF formats with server-generated filenames.

7. Technical Challenges and Contributions

7.1 Challenge 1: Unstructured Resume Parsing & Noise Reduction

Potential Issue: Undergraduate resumes exhibit diverse formatting choices, two-column table layouts, and graphical artifacts. Standard text extractors often merge columns horizontally or introduce garbled unicode tokens, corrupting keyword identification.

Resolution Approach: We engineered coordinate-based layout reconstruction using pdfplumber. Characters are grouped into logical words and lines by topological y-axis thresholds before regex boundary matching is applied against our canonical skill dictionary.

7.2 Challenge 2: Vector Normalization & Dynamic Skill Gap Alignment

Potential Issue: Job descriptions contain substantial generic conversational prose (e.g., "fast-paced environment"), while student resumes focus on concise skill bullet points. Naive string matching produces inaccurate match percentages.

Resolution Approach: We tuned Scikit-learn TF-IDF vectorization with sub-linear term frequency scaling and l2-norm regularization. This ensures uncommon technical terms carry substantial weight while boilerplate terms are heavily discounted.
